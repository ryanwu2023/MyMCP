# MCP 公众号文章设计稿

## 目标

以 `wind-index-mcp` 项目为真实案例，介绍如何把企业内部 Oracle 数据库中的指数基础数据，安全封装成可供 WorkBuddy、Codex 等智能体调用的 MCP 服务。

文章只讲整体思路、架构决策和验证方法，不放具体代码。读者看完后应理解：为什么选择 MCP、为什么不能开放任意 SQL、服务如何分层、stdio 与 HTTP 如何取舍，以及如何为扩展其他数据表预留结构。

## 标题

《我把本地 Oracle 数据库，封装成了一个智能体可用的 MCP 服务》

## 目标读者

- 知道 AI，但尚未实际使用 MCP 的开发者；
- 已经使用 MCP，希望学习企业内部数据安全接入方式的开发者。

## 篇幅与形式

- 目标篇幅：3000～4000 字；
- 第一人称项目复盘口吻；
- 不展示代码；
- 包含一张整体架构图；
- 包含一张改造前的手工 SQL 查询截图，以及三张实际接入和调用截图；
- 具体操作和调用示例由作者后续补充，正文为其预留自然衔接位置。

## 叙事方式

采用“真实问题驱动 + 架构拆解”的方式。

开篇从“数据库里已经有数据，但智能体无法直接、安全地使用”切入。MCP 概念只做必要说明，不展开协议历史或底层细节。全文围绕一个问题推进：如何把内部数据库能力变成边界明确、可发现、可复用的智能体工具。

## 正文结构

1. **问题起点**：本地可以查询 Oracle，但 WorkBuddy、Codex 等智能体无法直接使用这些数据。
2. **为什么选择 MCP**：MCP 不只是一个 HTTP 接口，而是智能体可以发现、理解并按参数调用的工具契约。
3. **先划定安全边界**：只开放按代码精确查询、按名称模糊搜索两个只读工具；不接收 SQL；限定股票类指数；所有查询使用固定 SQL 和绑定参数。
4. **整体架构**：通过架构图展示智能体、传输方式、鉴权、MCP Server、Tools、Service、Repository 与 Oracle 的关系。
5. **分层设计原因**：解释入口层、工具层、领域服务层、数据访问层和基础设施层各自职责，以及这种结构如何支持扩展其他表。
6. **两种传输方式**：stdio 面向本地智能体；Streamable HTTP 面向局域网或外部智能体；HTTP 额外使用 Bearer API Key 和 Host 校验。
7. **实际接入效果**：依次展示 WorkBuddy 配置、WorkBuddy 查询结果和 Codex 查询结果。这里只做效果说明，详细使用过程由作者后续补充。
8. **容易踩的坑**：说明 `/mcp` 不是普通浏览器页面、stdio 日志不能写入标准输出、Oracle 类型要转成 JSON、LIKE 通配符需要转义、客户端配置变更后可能需要重启。
9. **验证方法与总结**：通过分层单元测试、stdio/HTTP 冒烟测试和真实 Oracle 查询验证服务；回到“把数据库连接变成受控业务工具”的核心观点。

## 架构图设计

采用横向数据流版式，从左到右展示：

`WorkBuddy / Codex → stdio 或 HTTP + API Key → MCP Server → Tools → Service → Repository → Oracle 指数表`

图中同时表达以下边界：

- HTTP 请求先经过 API Key 鉴权；
- stdio 与 HTTP 共用同一套 MCP Server 和领域逻辑；
- MCP 层只暴露两个参数化、只读工具；
- Repository 使用固定 SQL 和绑定参数；
- Oracle 位于内部数据边界内。

最终图片采用白色背景、清晰的大字号和少量蓝绿紫配色，适合公众号正文宽度阅读，并导出为 PNG。

## 截图安排

1. **手工 SQL 查询截图**：放在开篇问题背景中，说明改造前需要进入数据库客户端手工查询；明确截图只是原始查询方式，MCP 服务内部已改为固定 SQL 和绑定参数。
2. **WorkBuddy HTTP 配置截图**：放在“两种传输方式”之后，说明 URL、Bearer 鉴权和启用状态。真实 API Key 必须完整遮挡。
3. **WorkBuddy 查询结果截图**：说明智能体可以理解自然语言查询，并把 MCP 返回数据整理为表格。

截图只承担真实性证明和效果展示，不展开具体配置教程。

## 安全与脱敏要求

- 不出现真实数据库地址、用户名、密码或 API Key；
- WorkBuddy 配置截图中的 Bearer Token 必须完整打码；
- 正文配置示例只使用占位符；
- 不暗示 MCP 可以执行任意 SQL；
- 强调服务只读、参数化、最小工具面和局域网使用边界。
